# Changelog

## 1.1.1

- Fixed a crash when opening the menu: the quick tiles read some states (hidden files…) by running a command, which must not happen while the menu is being drawn. They are now read just before.

## 1.1.0

- New menu. A header shows how many enhancements are on; on/off controls (Dark Mode, Keep Awake, mute, hidden files…) are round tiles you can flip without the menu closing; one-shot actions are grouped by category; a new Enhancements submenu turns any enhancement on or off; settings, updates and quit have icons.
- New menu bar icon: the lightning bolt as an outline, drawn like the icons of the other Lightmaster apps (Declic, Relief).

## 1.0.0

First release: 70+ tools for Finder, windows, Dock, apps, keyboard, mouse, screen capture, screenshots, audio, clipboard, files, display, system and utilities; global shortcuts; Finder context menu extension; automatic updates.
