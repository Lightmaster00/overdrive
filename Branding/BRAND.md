# Overdrive — brand guide

**Name**: Overdrive. **Tagline**: *Power tools for your Mac.*

## Icon

A macOS tile (continuous corners) with a warm gradient from pink to orange, a grid of four
translucent tiles — the toolbox — and a white lightning bolt in relief over them: power added to
everything. Generated by `make-icon.py` → `icon.svg` → `icon-*.png` and `AppIcon.icns`.

The menu bar icon (`menubar-icon.svg`, drawn in code in `Brand.swift`) is a template image: the
four tiles as outlines with the bolt over them.
