# Overdrive — brand guide

**Name**: Overdrive. **Tagline**: *Power tools for your Mac.*

## Icon

A dashboard gauge on a graphite macOS tile (continuous corners): a glowing scale from cyan to amber
to red, the needle pushed into the red zone — the Mac running in overdrive. Generated by
`make-icon.py` → `icon.svg` → `icon-*.png` and `AppIcon.icns`.

The menu bar icon (`menubar-icon.svg`, drawn in code in `Brand.swift`) is the same gauge as a
template image: an open dial, three ticks of the high zone and the needle.

## Colors

| Name     | Hex       | Use |
|----------|-----------|-----|
| Cyan     | `#36C5F0` | start of the scale |
| Amber    | `#FFB020` | middle of the scale |
| Ignition | `#FF6A1A` | accents |
| Redline  | `#FF2D55` | needle, red zone |
| Graphite | `#1C1E24` | tile, dark backgrounds |

The interface uses the system accent color, like every Mac app.
